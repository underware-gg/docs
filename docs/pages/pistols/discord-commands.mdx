# Command Reference

Use [Player Commands](#player-commands) for Classic duels, onboarding, stats and accounts, [Gauntlet Commands](#gauntlet-commands) for solo adventures, or [Admin Commands](#admin-commands) for server settings and metrics. For the surrounding workflows, see [For Players](/pistols/discord-players), [The Gauntlet](/pistols/discord-gauntlet) and [For Server Admins](/pistols/discord-admins).

Only commands that perform an action are listed. Redirect-only legacy commands are omitted. Root `/verify` is not registered; use `/pistols verify`.

## Reading the Examples

Type `/` in Discord and select the command, then fill its named option fields. In the syntax below, `<user>`, `<channel>` and similar text are placeholders for your selection. Square brackets mean an option is optional; `a|b` means choose one value. Do not type the brackets or the alternatives literally. Boolean options use `true` for on and `false` for off.

For example, `/duel user opponent:<user>` means select **duel → user**, then choose a person in **opponent**. Start in a server with the bot installed; see [Before You Start](/pistols/discord-bot#before-you-start) if this is your first time.

## Root Commands

These are the three top-level command families. Choose a subcommand beneath each one:

| Root | Who it's for | What it contains |
| --- | --- | --- |
| [`/duel`](#duel) | Players | Quick access to targeted challenges, open challenges, and practice duels. |
| [`/pistols`](#pistols) | Players | Classic duels, Gauntlet adventures, inbox, player and duelist browsers, tutorial, stats, accounts and feedback. |
| [`/pistols-admin`](#admin-commands) | Server admins | Configuration and usage metrics; requires Manage Server. |

## Player Commands

Player commands are available through `/duel` and `/pistols`. Server and channel restrictions apply where described below.

### /duel

| Command | Arguments | What it does |
| --- | --- | --- |
| `/duel user` | `opponent` (user, required) | Challenges a specific player. |
| `/duel public` | none | Posts an open challenge. |
| `/duel bot` | none | Opens the Imp picker for a practice duel. |

These are permanent, functional aliases of `/pistols duel user`, `/pistols duel public`, and `/pistols duel bot`. They run the same flows with identical options and permissions. Both paths share the 5-second per-user duel cooldown, configured duel-channel restriction, and server-disable and maintenance gates.

**Syntax:** `/duel user opponent:<user>`, `/duel public`, or `/duel bot`.

**Reply visibility:** Private setup and move choices. Targeted invitations prefer private delivery; accepted matches and results are public. For the full behaviour, see [Targeted and Open Duels](#targeted-and-open-duels) and [Practice Duel](#practice-duel).

| `/pistols tutorial` | none | Opens onboarding, rules, and practice; optionally the story tutorial. |
| `/pistols duel user` | `opponent` (user, required) | Challenges a specific player. |
| `/pistols duel public` | none | Posts an open challenge. |
| `/pistols duel bot` | none | Opens the Imp picker for a practice duel. |

| `/pistols inbox` | none | Privately lists all outstanding invitations and accepted duels, oldest first. |
| `/pistols queue` | none | Opens the same durable inbox. |
| `/pistols players` | none | Privately browses server players, public activity and challenge controls. |

#### Help and Menu

**Syntax:** `/pistols help` or `/pistols menu`

Help explains Classic duels, the four move choices, pistol archetypes, and commands. Its slash-command reply is public.

Menu opens a private panel with Duel, Stats, History, Inbox, Tutorial, Balance, Server Status, Gauntlet and Help buttons. Duel and Gauntlet explain how to start those activities. Information opened through the menu stays private, including information that the corresponding slash command would post publicly.

**Cooldown:** None.

#### Tutorial

**Syntax:** `/pistols tutorial`

The default flow opens a private welcome with a short summary of the four choices. **Full rules** opens the longer explanation; **Back to welcome** returns to the summary. **Try it against the practice bot** starts a practice duel inside a server.

When the bot operator enables the optional story tutorial, this command and Tutorial buttons instead open three scripted NPC duels: first firing, then firing and dodging, then all four choices. These are scripted scenarios with fixed rolls and lessons responding to your choices; normal practice duels use the usual random rolls. Unfinished progress resumes across bot restarts without an inactivity limit. After the mandatory first lesson, you can skip the remaining lessons. Completion or skipping grants the starter pistol and Manual, and qualifies you for Duelist; it does not unlock all pistol archetypes.

Completed lessons remain visible as you continue. The story flow is off by default (`TUTORIAL_ENABLED=false`).

**Reply visibility:** Private. **Cooldown:** None.

#### Targeted and Open Duels

**Syntax:** `/pistols duel user opponent:<user>` or `/pistols duel public`

Both open a private premise picker. Selecting a themed reason needs no extra form; Custom requires text, up to 80 characters. The challenger’s private confirmation offers **State your grievance** for optional detail while the challenge awaits a response. A blank submission changes nothing.

A targeted challenge enters both players’ durable inboxes. Notification delivery tries enabled DMs, then an enabled private thread, then a public challenge. Private threads include the recipient and bot; moderators can also see them. Closed DMs do not remove the invitation: use `/pistols inbox`. Another outstanding challenge between the same pair reopens that duel instead of creating a duplicate.

An open challenge posts publicly; the first valid accepter other than the challenger takes it. You can have one unanswered open challenge per server. Other unfinished Classic duels do not reserve either player or put a new targeted invitation in a waiting queue.

Duel commands require a server and its configured duel channel when one is set. **To the Duelling Grounds** opens private controls suited to your role, or a status panel for spectators. Invitations and accepted Classic duels have no inactivity expiry.

The challenger can choose **Call Them Out** once to announce a targeted challenge publicly. Optional settlement needs an explicit timezone, for example `2026-11-20T20:00+11:00`, and must be at least 24 hours after the callout is issued. The deadline is fixed when posted and applies even before acceptance. Leave it blank for an indefinite callout.

Unscheduled duels resolve after acceptance and both hands are committed. Scheduled duels hold the hands until settlement. Missing acceptance or moves then cancels the duel and publicly shames every unready participant. Rejection and withdrawal can also carry public shame; these social outcomes do not award combat wins or pistol unlocks. See [For Players](/pistols/discord-players) for the full callout, settlement and spectator prediction flow.

**Reply visibility:** Private picker, confirmation and inbox; private notifications when available; public open challenges, callouts, accepted matches and results.

**Cooldown:** 5 seconds per user, shared across all three variants and both `/duel` and `/pistols duel` paths.

#### Practice Duel

**Syntax:** `/pistols duel bot`

Opens a private Imp card picker inside a server. Browse with **Previous** and **Next**, then choose **Duel this Imp**. It starts on Nasty Imp; Veteran unlocks after your first Imp victory. Once the duel starts, the Imp commits immediately and you choose your moves through the private Duelling Grounds panel. There is no premise picker or acceptance step. Normal duel channel and server restrictions apply.

The result does not affect your win/loss record. A resolved practice duel advances normal pistol unlocks and counts toward the Duelist badge. Imp victories fill four trophy slots under `/pistols stats`, shared across servers. Replay opens a private animation; Replay and Combat Log remain available while the saved result exists. The tutorial’s practice button uses a random eligible Imp rather than this picker.

**Reply visibility:** Private confirmation and move choices; public duel and result.

**Cooldown:** The shared 5-second duel cooldown, including `/duel bot`.

#### Stats, History and Inbox

**Syntax:** `/pistols stats`, `/pistols history`, `/pistols inbox` or `/pistols queue`

- **Stats:** wins, losses, draws, win rate, current/best streak and four Imp trophy slots. The reply is public when you have a record or trophies; the no-history prompt is private.
- **History:** a bounded summary of outstanding duels and your last 10 resolved duels. In a server, results are scoped to that server. The reply is private.
- **Inbox:** all outstanding invitations and accepted duels, oldest first, with pagination and private controls. You can answer or complete different duels in any order. `/pistols queue` opens this same inbox.

Draft choices survive restarts until you commit or the duel closes. Committed moves remain secret and locked. Use the inbox to recover an invitation when notification delivery fails.

**Cooldown:** None.

#### Player and Duelist Browsers

**Syntax:** `/pistols players` or `/pistols duelists`

**Players** privately browses activity in the current server. Search a member, change sorting, replay a recent Classic duel or open the standard challenge picker. Private unanswered invitations are excluded from public activity. Challenges still honour the configured duel channel.

**Duelists** privately browses 96 cards across Imps, Characters, Genesis, Legends and Pirates. Change collection with the menu and page through the cards. Browsing a card does not start a duel or require you to own it.

**Reply visibility:** Private. Players requires a server. **Cooldown:** None.

#### Verify

**Syntax:** `/pistols verify`

Requires a server. In Underware, claims configured recognition roles you qualify for:

- **Duelist:** any resolved duel, including practice, or recorded qualification from the optional story tutorial. Refused, withdrawn, and expired duels do not qualify.
- **Guild Owner:** ownership of a server with the bot installed, or ownership recorded when it was installed earlier.

Outside Underware, it reports eligibility and includes the official-server invite when configured; it does not grant roles there. Use it to recover a failed automatic role grant or a badge after joining or rejoining Underware. Role delivery depends on the bot's badge configuration.

**Reply visibility:** Private. **Cooldown:** 10 seconds per user.

#### Account Link

**Syntax:** `/pistols account link username:<text>`

Verifies that the Cartridge Controller username is already linked to this same Discord account in Pistols, then saves a local convenience mapping. It does not create a wallet or establish the external Discord link. Unknown usernames, missing Discord links, and links to another Discord user are rejected.

**Reply visibility:** Private. **Cooldown:** None.

#### Account Balance

**Syntax:** `/pistols account balance [user:<user>]`

Defaults to yourself. Shows LORDS, FOOLS, FAME, and STRK balances, or a Not Linked message. The bot first checks the Discord-to-wallet identity in Pistols, then falls back to its local account-link mapping. Your own Not Linked response offers a **Link wallet** button that opens the linking form.

**Reply visibility:** Public when invoked as a slash command; private through Menu. **Cooldown:** None.

#### Account Unlink

**Syntax:** `/pistols account unlink`

Removes the mapping from the bot's local profile store. Reports success, nothing linked, or a removal failure. This does not unlink your external Cartridge/Pistols identity; balance lookup can still find an external Discord-to-wallet link.

**Reply visibility:** Private. **Cooldown:** None.

#### Server Status

**Syntax:** `/pistols server status`

Shows the indexer head and world tails for Mainnet, or reports that the game indexer could not be reached.

**Reply visibility:** Public when invoked as a slash command; private through Menu. **Cooldown:** None.

#### Feedback

**Syntax:** `/pistols feedback category:<bug|suggestion|praise|other> [attachment:<file>]`

Opens a modal for a 10–1000 character message. The feedback is authored: the team receives your Discord identity and server context. An optional screenshot or recording attached to the command is saved with the submission and needs no access to channel messages.

If the operator enables the separate post-submit attachment fallback and you supplied no file, the confirmation offers **Add a screenshot or recording**. Clicking it starts a 5-minute window: your next message in that channel containing an attachment is captured and acknowledged with ✅. This fallback is off by default.

When the bot has a configured team feedback inbox, staff can reply to the submission by DM. Closed DMs can prevent delivery.

**Reply visibility:** Private form and confirmation; feedback goes to the team.

**Rate limit:** 3 submissions per user per hour.

## Gauntlet Commands

Solo adventures use `/pistols gauntlet`. For the full run, combat and progression guide, see [The Gauntlet](/pistols/discord-gauntlet).

Start in an enabled server channel where the bot can post the public run view. The bot needs View Channel, Embed Links, Read Message History and Send Messages there, or Send Messages in Threads in a thread. One active run per player is shared across servers. Gameplay and item changes belong to the owner and original run channel; losing access preserves progress. The Classic `duel_channel` setting does not move or restrict a Gauntlet run.

| Command | Arguments | What it does |
| --- | --- | --- |
| `/pistols gauntlet start` | Optional `advancement`, `easy_road`, `skip_reward`; see below | Previews next-run choices, then asks for confirmation. Resumes an active run instead of replacing it. |
| `/pistols gauntlet status` | none | Shows your saved run and its original channel. |
| `/pistols gauntlet inventory` | none | Shows equipment, bag and consumable controls, or your pending next-run reward. |
| `/pistols gauntlet equip` | none | Opens a named picker for owned equipment. |
| `/pistols gauntlet unequip` | Required `slot`; see below | Moves equipped gear into your bag. |
| `/pistols gauntlet use` | none | Opens a named consumable picker with its effect and use restrictions. |
| `/pistols gauntlet discard` | none | Opens a named picker for an owned item to discard. |
| `/pistols gauntlet sell` | none | Shows named sale quotes; selling requires a shop. |
| `/pistols gauntlet rewards` | none | Inspects next-run item choices and permanent Gauntlet achievements. |
| `/pistols gauntlet history` | none | Pages completed runs and their chronicle downloads. |
| `/pistols gauntlet leaderboard` | none | Shows the global top ten best successful-run Fame scores. |
| `/pistols gauntlet chronicle` | none | Downloads your latest completed adventure as a shareable text file. |
| `/pistols gauntlet abandon` | none | Ends your active run; committed first-blood stakes are forfeited. |

**Start options:** `advancement:<aim|nerve|reflex|grit|cunning|luck>` chooses an earned advancement; `easy_road:<true|false>` selects the easier difficulty; `skip_reward:<true|false>` explicitly leaves a pending next-run item behind. All are optional. Review the preview before confirming.

**Unequip slots:** `head`, `chest`, `gloves`, `boots`, `belt`, `weapon`, `necklace`, `ring`, `ring2` or `codpiece`. The other item commands use named pickers rather than an item argument.

**Reply visibility:** The run view and leaderboard are channel-visible. Other command replies, inventory, history, rewards and downloads are private. Spectators cannot change someone else’s run. Fame and coins belong to the run, separate from wallet tokens. Inactivity ends a run after fourteen days; status shows the saved deadline. Abandoning does not require access to the original run channel.

**Cooldown:** None. The five-second duel cooldown does not apply to Gauntlet commands.

## Admin Commands

Server administration uses `/pistols-admin`. These commands require **Manage Server** (Discord's `Manage Guild` permission) and only work inside a server. Both reply privately and have no command cooldown.

| Command | Arguments | What it does |
| --- | --- | --- |
| `/pistols-admin config` | All options optional; see below | Views or changes server configuration and the control-room hub. |
| `/pistols-admin metrics` | `period`, `global` (both optional) | Shows usage metrics for this server or an authorised cross-server aggregate. |


### Configuration

**Syntax:** `/pistols-admin config [duel_channel:<channel>] [animation:<true|false>] [speed:<normal|compact|minimal>] [duel_dms:<true|false>] [duel_threads:<true|false>] [enabled:<true|false>] [hub_channel:<channel>] [hub_action:<refresh|remove>]`

All options are optional. With no options, shows the current settings and re-checks the configured duel channel's permissions and existence.

| Option | Type | Behaviour |
| --- | --- | --- |
| `duel_channel` | Text channel | Restricts Classic duel commands to that channel; warns about missing bot permissions. |
| `animation` | Boolean | Enables or disables live ASCII animation. |
| `speed` | String choice | `normal`, `compact`, or `minimal`. |
| `duel_dms` | Boolean, default `true` | Tries DM notifications for targeted invitations. |
| `duel_threads` | Boolean, default `true` | Tries private-thread notifications when DMs are disabled or unavailable. |
| `enabled` | Boolean | Enables/disables interactions in this server; config remains reachable to re-enable it. |
| `hub_channel` | Text channel | Posts and saves a new control-room panel, then attempts to pin it. Old panels and pins remain. |
| `hub_action` | String choice | `refresh` updates the saved panel; `remove` forgets its configuration and leaves the message/pin. |

Do not combine `hub_channel` and `hub_action`: the whole request is rejected before any settings change. A refresh only publishes a replacement if no message ID is saved or Discord confirms the saved message was deleted. Permission or network failures do not create another panel. Failed pinning does not invalidate a saved hub.

Classic invitations and accepted duels have no inactivity expiry. The former `accept_timeout` option is removed; only a scheduled callout has a settlement deadline.

See [Duel Notifications](/pistols/discord-admins#duel-notifications) for fallback and thread permissions, and [Control-Room Hub](/pistols/discord-admins#control-room-hub) for hub buttons and cleanup.

### Metrics

**Syntax:** `/pistols-admin metrics [period:<choice>] [global:<true|false>]`

Choose 7 days (default), 30 days, 90 days, or all time from Discord's period choices. Shows active players, duels created/resolved, completion rate, win/loss/draw counts, average duel duration, and the top commands used.

`global:true` aggregates all servers, and additionally requires the bot's configured team allowlist. Other admins must omit it.
