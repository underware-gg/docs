# Command Reference

Commands are grouped below by their root: server administration uses `/pistols-admin`, and player commands are nested under `/pistols`. This page covers their options, reply visibility, and cooldowns. For the surrounding workflows, see [For Players](/pistols/discord-players) and [For Server Admins](/pistols/discord-admins).

Only commands that perform an action are listed. Redirect-only legacy commands are omitted. Root `/duel` and `/verify` have been removed; use `/pistols duel user`, `/pistols duel public`, `/pistols duel bot`, and `/pistols verify`.

## Root Commands

Server administration uses the `/pistols-admin` root command:

| Command | Arguments | What it does |
| --- | --- | --- |
| `/pistols-admin config` | All options optional; see below | Views or changes server configuration and the control-room hub. |
| `/pistols-admin metrics` | `period`, `global` (both optional) | Shows usage metrics for this server or an authorized cross-server aggregate. |

Both commands require **Manage Server** (Discord's `Manage Guild` permission) and only work inside a server. Both reply privately and have no command cooldown.

### Configuration

**Syntax:** `/pistols-admin config [duel_channel:<channel>] [animation:<true|false>] [speed:<normal|compact|minimal>] [accept_timeout:<minutes>] [enabled:<true|false>] [hub_channel:<channel>] [hub_action:<refresh|remove>]`

All options are optional. With no options, shows the current settings and re-checks the configured duel channel's permissions and existence.

| Option | Type | Behavior |
| --- | --- | --- |
| `duel_channel` | Text channel | Restricts duel commands to that channel; warns about missing bot permissions. |
| `animation` | Boolean | Enables or disables live ASCII animation. |
| `speed` | String choice | `normal`, `compact`, or `minimal`. |
| `accept_timeout` | Integer minutes | `0` clears the override; otherwise 5–2880. Values 1–4 are rejected. The usual default is 5 minutes. |
| `enabled` | Boolean | Enables/disables interactions in this server; config remains reachable to re-enable it. |
| `hub_channel` | Text channel | Posts and saves a new control-room panel, then attempts to pin it. Old panels and pins remain. |
| `hub_action` | String choice | `refresh` updates the saved panel; `remove` forgets its configuration and leaves the message/pin. |

Do not combine `hub_channel` and `hub_action`: the whole request is rejected before any settings change. A refresh only publishes a replacement if no message ID is saved or Discord confirms the saved message was deleted. Permission or network failures do not create another panel. Failed pinning does not invalidate a saved hub.

See [Control-Room Hub](/pistols/discord-admins#control-room-hub) for permissions, buttons, and cleanup.

### Metrics

**Syntax:** `/pistols-admin metrics [period:<choice>] [global:<true|false>]`

Choose 7 days (default), 30 days, 90 days, or all time from Discord's period choices. Shows active players, duels created/resolved, completion rate, win/loss/draw counts, average duel duration, and the top commands used.

`global:true` aggregates all servers, and additionally requires the bot's configured team allowlist. Other admins must omit it.

| `/pistols duel public` | none | Posts an open challenge. |

### Help and Menu

**Syntax:** `/pistols help` or `/pistols menu`

Help explains Classic duels, the four move choices, pistol archetypes, and commands. Its slash-command reply is public.

Menu opens a private panel with buttons for Duel, Stats, History, Queue, Balance, Server Status, Help, and Tutorial. Duel shows how to start a challenge; it does not immediately create one. Results opened through the menu stay private, including information that the corresponding slash command would post publicly.

**Cooldown:** None.

### Tutorial

**Syntax:** `/pistols tutorial`

The default flow opens a private welcome with a short summary of the four choices. **Full rules** opens the longer explanation; **Back to welcome** returns to the summary. **Try it against the practice bot** starts a practice duel inside a server.

When the bot operator enables the optional story tutorial, this command and Tutorial buttons instead open three scripted NPC duels: first firing, then firing and dodging, then all four choices. These are scripted scenarios with fixed rolls and lessons responding to your choices; normal practice duels use the usual random rolls. Unfinished progress resumes across bot restarts without an inactivity limit. After the mandatory first lesson, you can skip the remaining lessons. Completion or skipping grants the starter pistol and Manual, and qualifies you for Duelist; it does not unlock all pistol archetypes.

Completed lessons remain visible as you continue. The story flow is off by default (`TUTORIAL_ENABLED=false`).

**Reply visibility:** Private. **Cooldown:** None.

### Targeted and Open Duels

**Syntax:** `/pistols duel user opponent:<user>` or `/pistols duel public`

Both open a private premise picker. Selecting a themed reason needs no extra form. Custom requires text, up to 80 characters. Submitting posts a public challenge: targeted challenges name and ping the opponent; open challenges let an eligible, free player other than the challenger accept.

For immediately posted challenges, the private confirmation offers **State your grievance** to add optional detail while the challenge awaits a response. A blank submission changes nothing. Queued targeted challenges do not offer this button.

Duel commands must run inside a server, in its configured duel channel when one is set. Targeted challenges can queue while either player is busy. Open challenges do not queue. The **To the Duelling Grounds** button opens private controls suited to your role in the duel, or a status panel for spectators.

**Reply visibility:** Private picker and confirmation; public challenge and result.

**Cooldown:** 5 seconds per user, shared across all three `/pistols duel` variants.

### Practice Duel

**Syntax:** `/pistols duel bot`

Starts a Classic duel against a practice bot inside a server. There is no acceptance step or premise picker: the bot commits immediately, and you choose and confirm your moves through the private Duelling Grounds panel. Normal duel availability and channel restrictions still apply.

The result does not affect your win/loss record. A resolved practice duel advances normal pistol unlocks and counts toward the Duelist badge.

**Reply visibility:** Private confirmation and move choices; public duel and result.

**Cooldown:** The shared 5-second duel cooldown.

### Stats, History, and Queue

**Syntax:** `/pistols stats`, `/pistols history`, or `/pistols queue`

- **Stats:** total wins, losses, draws, win rate, and current/best streak. The reply is public when you have a stats record; the no-history prompt is private.
- **History:** active and queued duels, including pre-commit status, followed by your last 10 resolved duels. In a server, results are scoped to that server. The reply is private.
- **Queue:** your queued duels in this server, with opponent, premise, age, expiry, and waiting/next status. The reply is private.

Queued Classic move selection is optional. Target pre-commit also records acceptance; without it, the target still needs to accept after the queued challenge activates. Draft choices persist through queue activation and bot restarts until you commit or the duel closes. An open picker follows the same duel when it activates; stale controls cannot replace already locked moves.

**Cooldown:** None.

### Verify

**Syntax:** `/pistols verify`

Requires a server. In Underware, claims configured recognition roles you qualify for:

- **Duelist:** any resolved duel, including practice, or recorded qualification from the optional story tutorial. Refused, withdrawn, and expired duels do not qualify.
- **Guild Owner:** ownership of a server with the bot installed, or ownership recorded when it was installed earlier.

Outside Underware, it reports eligibility and includes the official-server invite when configured; it does not grant roles there. Use it to recover a failed automatic role grant or a badge after joining or rejoining Underware. Role delivery depends on the bot's badge configuration.

**Reply visibility:** Private. **Cooldown:** 10 seconds per user.

### Account Link

**Syntax:** `/pistols account link username:<text>`

Verifies that the Cartridge Controller username is already linked to this same Discord account in Pistols, then saves a local convenience mapping. It does not create a wallet or establish the external Discord link. Unknown usernames, missing Discord links, and links to another Discord user are rejected.

**Reply visibility:** Private. **Cooldown:** None.

### Account Balance

**Syntax:** `/pistols account balance [user:<user>]`

Defaults to yourself. Shows LORDS, FOOLS, FAME, and STRK balances, or a Not Linked message. The bot first checks the Discord-to-wallet identity in Pistols, then falls back to its local account-link mapping. Your own Not Linked response offers a **Link wallet** button that opens the linking form.

**Reply visibility:** Public when invoked as a slash command; private through Menu. **Cooldown:** None.

### Account Unlink

**Syntax:** `/pistols account unlink`

Removes the mapping from the bot's local profile store. Reports success, nothing linked, or a removal failure. This does not unlink your external Cartridge/Pistols identity; balance lookup can still find an external Discord-to-wallet link.

**Reply visibility:** Private. **Cooldown:** None.

### Server Status

**Syntax:** `/pistols server status`

Shows the indexer head and world tails for Mainnet, or reports that the game indexer could not be reached.

**Reply visibility:** Public when invoked as a slash command; private through Menu. **Cooldown:** None.

### Feedback

**Syntax:** `/pistols feedback category:<bug|suggestion|praise|other> [attachment:<file>]`

Opens a modal for a 10–1000 character message. The feedback is authored: the team receives your Discord identity and server context. An optional screenshot or recording attached to the command is saved with the submission and needs no access to channel messages.

If the operator enables the separate post-submit attachment fallback and you supplied no file, the confirmation offers **Add a screenshot or recording**. Clicking it starts a 5-minute window: your next message in that channel containing an attachment is captured and acknowledged with ✅. This fallback is off by default.

When the bot has a configured team feedback inbox, staff can reply to the submission by DM. Closed DMs can prevent delivery.

**Reply visibility:** Private form and confirmation; feedback goes to the team.

**Rate limit:** 3 submissions per user per hour.
